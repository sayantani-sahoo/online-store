# Modern Online Store Homepage 🚀

## ✨ Features
- **Fully Responsive** - Mobile, tablet, desktop
- **Dynamic Filtering** - Category tabs, price slider, ratings
- **Real-time Search** - Type to filter products
- **Sorting** - Price low/high, rating high
- **Interactive Cart** - Add to cart, toast notifications, persistent count
- **Modern UI** - CSS Grid/Flexbox, smooth animations, hover effects
- **24 Products** - Electronics, Fashion, Home Appliances, Books

| File | Purpose |

| `index.html` | Complete page structure |

## 🎮 How to Run
```
# Windows
start index.html
```
